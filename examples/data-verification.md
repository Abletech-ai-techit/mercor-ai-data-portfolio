# Data Verification Sample

## Task Overview

This sample demonstrates a basic data verification workflow used in AI data annotation and quality-control tasks.

The objective is to compare information against a provided source and determine whether the information is accurate.

## Verification Process

1. Review the provided information carefully.
2. Compare the information with the available source.
3. Check names, numbers, dates, labels, and other relevant details.
4. Identify any discrepancies or missing information.
5. Mark the information as correct or incorrect based on the task guidelines.
6. Review the result before submission.

## Example

| Field | Source Information | Submitted Information | Result |
|---|---|---|---|
| Product Name | Wireless Mouse | Wireless Mouse | Correct |
| Quantity | 5 | 5 | Correct |
| Category | Computer Accessories | Computer Accessories | Correct |
| Model | WM-2025 | WM-2026 | Incorrect |
