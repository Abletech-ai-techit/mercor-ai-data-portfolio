# Information Extraction Sample

## Task Overview

This sample demonstrates a basic information extraction workflow used in AI data and data annotation tasks.

The objective is to identify relevant information from a provided source and record it accurately in a structured format.

## Extraction Process

1. Review the source carefully.
2. Identify the information required by the task.
3. Extract the relevant names, numbers, dates, labels, or other details.
4. Record the information in a structured format.
5. Check the extracted information against the original source.
6. Review the final result for accuracy.

## Example

Suppose an image contains the following information:

**Product:** Wireless Keyboard  
**Brand:** ExampleTech  
**Model:** WK-2025  
**Quantity:** 3  
**Category:** Computer Accessories

The extracted information can be organized as:

| Field | Extracted Information |
|---|---|
| Product | Wireless Keyboard |
| Brand | ExampleTech |
| Model | WK-2025 |
| Quantity | 3 |
| Category | Computer Accessories |

## Quality Checks

During information extraction, I focus on:

- Reading the source carefully
- Capturing the correct information
- Preserving the original meaning
- Avoiding missing or duplicated information
- Checking extracted information against the source
- Following project-specific instructions
