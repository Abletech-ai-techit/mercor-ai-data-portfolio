# Image Annotation Sample

## Task Overview

This sample demonstrates a basic image annotation workflow for AI data projects.

The objective is to identify relevant objects or elements in an image and assign appropriate labels according to the task instructions.

## Annotation Process

1. Review the image carefully.
2. Identify the objects or elements that need to be labeled.
3. Determine the correct label for each identified item.
4. Apply the labels consistently.
5. Check the annotations for accuracy.
6. Review the completed work before submission.
