# Data Categorization Sample

## Task Overview

This sample demonstrates a basic data categorization workflow used in AI data annotation and classification tasks.

The objective is to assign information to the appropriate category based on defined rules and task instructions.

## Categorization Process

1. Review the information carefully.
2. Understand the available categories.
3. Identify the characteristics of the item.
4. Select the most appropriate category.
5. Apply the category consistently.
6. Review the classification before submission.

## Example

| Item | Description | Assigned Category |
|---|---|---|
| Laptop | Portable computer | Electronics |
| Smartphone | Mobile communication device | Electronics |
| Notebook | Paper stationery | Stationery |
| Ballpoint Pen | Writing instrument | Stationery |
| Coffee Mug | Drinking container | Household Item |

## Classification Considerations

When categorizing information, I focus on:

- Understanding the category definitions
- Identifying the key characteristics of each item
- Selecting the most appropriate category
- Applying categories consistently
- Avoiding assumptions when information is unclear
- Following project-specific guidelines

## Quality Checks

Before submitting a categorization task, I review:

- Whether each item has a category
- Whether the selected category matches the item
- Whether similar items have been categorized consistently
- Whether the task instructions have been followed
